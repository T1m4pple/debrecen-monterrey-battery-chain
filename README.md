# Debrecen–Monterrey Battery Chain

Interactive presentation: transport chain for EV battery modules from Debrecen, Hungary to Monterrey, Mexico.

Live: https://t1m4pple.github.io/debrecen-monterrey-battery-chain/

## Editing

Everything is in `index.html`. To change text, open the file on GitHub, click the pencil icon, edit, and commit to `main`. The site updates about a minute later.

- Slide text is plain HTML inside each `<section class="slide">`.
- Speaker notes are in the `<aside class="notes">` under each slide.
- Presenter names: the `TEAM` list near the top of the `<script>`.
- Cost items: the `COST` list in the script; the greener option's extra cost is `GREEN_EXTRA`.

The in-page **Edit E** button only works on the claude.ai copy; here it stays disabled.
